## Технические заметки

- Статический HTML/CSS/JS, без сборки и зависимостей.
- Фото и логотип лежат локально в `img/`, внешний интернет нужен только для шрифтов.
- `prefers-reduced-motion` отключает анимации.
- В наброске проект был на React + Vite + Tailwind; текущая версия — чистая вёрстка,
  при необходимости переносится в React посекционно.
